# Amo Daily News

个人新闻阅读网站。已确认内容基线：每日五类新闻＋按需特别关注＋每周专题＋周日 Weekend Special。

网站使用 GitHub Pages，首页 `index.html`，归档页面放在 `issues/YYYY-MM-DD/index.html`。不上传个人阅读反馈等私人数据。

## 发布与对话交付｜APPROVED（2026-10-16）

每日 Daily News v2.0 内容与 Knowledge/File QA 通过后，将当期交互 HTML、完整文字版 PDF、中国平台友好版 PDF 一并上传本仓库相应 `issues/YYYY-MM-DD/` 目录，更新首页和归档，并回读验证三个文件链接有效；只有三份都可用才标 COMPLETE。聊天默认只发送当期 GitHub Pages 阅读链接，不单独发送 PDF 沙盒下载链接；仅在 Amo 当天明确额外索取 PDF 时提供。发布失败应说明具体未通过项目，不得伪称完整发布，不得因此暂停、停用、删除或更改原 Daily News Scheduled Task、Asia/Shanghai 10:00 排程或既有 LOCKED 规范。此发布约定适用于未来期刊，不追溯更改旧稿。
